# Voz AuK como padrão (ROADMAP §13) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A voz com que o assistente **fala** passa a ser gerada pelo AuK (Tencent Hunyuan) rodando local na RTX 5070, virando a voz padrão do app, **desde que** o teste da Task 1 aprove português e tempo de resposta. As vozes Piper atuais continuam como alternativa.

**Architecture:** O AuK roda pelo `audio.cpp`, a versão em C++ que lê os arquivos GGUF (sem Python), com build CUDA para Windows. É o mesmo jeito que o app já roda o sd.cpp. Uma receita em `tools.rs` baixa o `audiocpp_cli` e os pesos GGUF. Um módulo `auk.rs` chama o CLI sem janela e devolve o WAV. `speech.rs` passa a aceitar a voz `tts-auk-flash` ao lado das vozes Piper. O resto do app (SpeechController, "barge-in", Configurações) já trabalha com "id de voz → WAV" e não muda.

**Tech Stack:** Rust (Tauri 2), `audio.cpp` v0.8.2 (CUDA 12.4, Windows), GGUF de `huggingface.co/audio-cpp/AuK-Base-and-Flash-GGUF`, TypeScript/Vitest.

**Spec:** `docs/ROADMAP.md` §13. O que já se sabe do AuK (pesquisado em 2026-09-26):
- É **geração** de voz (fala e edição de áudio), não reconhecimento. Então substitui a voz de **saída** (hoje Piper/sherpa-onnx); a voz de entrada continua com NeMo/Whisper.
- Licença MIT (gratuito, inclusive os pesos).
- Modelo de 1,5B + Qwen2.5-Omni-3B (entende a instrução) + um decodificador (VAE). Arquivos: `auk-flash-q8_0.gguf` (1,6 GB), `auk-vae-f32.gguf` (0,64 GB), `qwen2.5-omni-3b-q8_0.gguf`, `config/auk-flash.yaml`, `tokenizer/*`.
- Exemplos oficiais só em inglês e chinês: **português não confirmado.**
- CLI: `audiocpp_cli --task tts --family auk --model <pasta> --backend cuda --text "…" --request-option "instruct=<descrição da voz>" --request-option auk.variant=flash --out fala.wav`. Saída mono, 24 kHz.
- Divide a GPU com o Ollama: igual à geração de imagens, descarregar os modelos do Ollama antes (`imagegen::unload_ollama_models()`).

```rust
pub fn cli_args(model_dir: &Path, text: &str, instruct: &str, out: &Path) -> Vec<String> {
    [
        "--task", "tts", "--family", "auk", "--model", &model_dir.to_string_lossy(), "--backend", "cuda",
        "--text", text, "--request-option", &format!("instruct={instruct}"), "--request-option", "auk.variant=flash",
        "--out", &out.to_string_lossy(),
    ].iter().map(|part| part.to_string()).collect()
}

fn cli(app: &AppHandle) -> Result<PathBuf, String> {
    let dir = tools::tool_dir(app, tools::AUDIOCPP_RUNTIME)?;
    tools::find_file(&dir, &|name| name == "audiocpp_cli.exe").ok_or_else(|| "audiocpp_cli.exe não encontrado (reinstale a voz AuK).".into())
}

pub fn synthesize(app: &AppHandle, text: &str) -> Result<Vec<u8>, String> {
    if !tools::is_installed(app, AUK_VOICE) { return Err("Voz AuK não instalada.".into()); }
    let exe = cli(app)?;
    let model = tools::tool_dir(app, AUK_VOICE)?;
    let out = std::env::temp_dir().join(format!("oa-auk-{}.wav", std::process::id()));
    imagegen::unload_ollama_models();
    let output = Command::new(&exe)
        .args(cli_args(&model, text, DEFAULT_INSTRUCT, &out))
        .current_dir(exe.parent().unwrap_or(Path::new(".")))
        .creation_flags(CREATE_NO_WINDOW)
        .output()
        .map_err(|error| format!("Não foi possível rodar o AuK: {error}"))?;
    if !output.status.success() { return Err(format!("AuK falhou: {}", String::from_utf8_lossy(&output.stderr).trim())); }
    let bytes = fs::read(&out).map_err(|error| error.to_string())?;
    let _ = fs::remove_file(&out);
    Ok(bytes)
}
```
